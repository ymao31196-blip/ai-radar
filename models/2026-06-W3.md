## WWDC 2026 实际发布：Siri AI、iOS 27、Apple Intelligence 增强

**日期**：2026-06-09（Keynote 发布）
**提供方**：Apple
**来源**：[Apple Newsroom — Siri AI](https://www.apple.com/newsroom/2026/06/apple-introduces-siri-ai-a-profoundly-more-capable-and-personal-assistant/) ｜ [TechCrunch 回顾](https://techcrunch.com/2026/06/09/wwdc-2026-everything-announced-on-siri-ai-os-27-apple-intelligence-and-more/)
**可信度**：🟢 官方

### 是什么
- 模型类型：Apple 本地模型 + 云端 Apple Intelligence（Siri 后端为 Apple 自研，非 Gemini）
- 核心亮点：
  - **Siri AI**：全新版本，具备个人上下文理解、广泛世界知识、屏幕感知能力
  - 独立 Siri 应用未提及；Siri 深度集成到 iOS 27 / macOS 中
  - **Apple Intelligence** 新增功能：通知智能摘要、写作工具增强、Genmoji 2.0、Image Playground 升级
  - **Liquid Glass** 设计语言：跨所有平台的视觉统一
  - 家长控制（Parental Controls）AI 辅助功能
  - AI Agent App Store：第三方 Agent 分发，可跨应用执行任务

### 有什么用
- **与前瞻的关键差异**：Siri AI 由 Apple 自研模型驱动（非 Gemini），iOS/macOS 开发者需跟踪 Apple Intelligence API 而非 Gemini API
- **Agent 分发渠道确认**：AI Agent App Store 成为现实，第三方 AI Agent 有了系统级分发渠道 — 类比 2008 年 App Store 对移动开发者的影响
- **Liquid Glass 设计**：AI 应用 UI 范式的信号 — 半透明、深度、自适应交互
- **本地+云端混合架构**：Apple 的隐私优先 AI 策略对 B2C AI 产品的技术选型有参考价值

### 关键数据
| 指标 | 值 |
|------|-----|
| Siri AI 后端 | Apple 自研模型（非 Gemini） |
| Apple Intelligence 功能数 | 新增 12+ 项 |
| AI Agent App Store | 确认，随 iOS 27 推出 |
| Liquid Glass 平台覆盖 | iOS / iPadOS / macOS / watchOS / visionOS |

### 行动项
- [x] WWDC 前瞻 → 实际发布差异已记录（Siri AI ≠ Siri+Gemini）
- [ ] iOS 开发者：跟踪 Apple Intelligence API 文档更新（developer.apple.com）
- [ ] 评估 AI Agent App Store 作为新产品分发渠道的可能性

## Qwen3.6-Plus — 面向真实世界 Agent 的编码增强

**日期**：2026-06（正式发布）
**提供方**：Alibaba Cloud（通义千问团队）
**来源**：[Qwen 官方博客](https://qwen.ai/blog?id=qwen3.6)
**可信度**：🟢 官方

### 是什么
- 模型类型：LLM（Dense），支持 Agentic Coding
- 核心亮点：
  - 基于 Qwen3.5 架构，大幅增强 Agentic 编码能力
  - 从前端 Web 开发到复杂仓库级编程任务
  - 强调"面向真实世界 Agent"的稳定性和实用性
  - Qwen3.7-Max 已在 Apsara Summit（5月20日）发布，为闭源 Max 系列

### 有什么用
- **开源 Agent 编码方案**：Qwen3.6-Plus 是当前最强的开源 Agentic coding 模型之一，适合自部署 coding agent
- **替代闭源**：如果 Anthropic/OpenAI 价格上涨或配额不足，Qwen3.6 可作为开源备选
- **中文 Agent 场景**：中文编码和任务理解的天然优势

### 关键数据
| 指标 | 值 |
|------|-----|
| 系列 | Qwen3.5 → 3.6-Plus → 3.7-Max |
| 开源状态 | Qwen3.6-Plus 开放权重 |
| 3.7-Max 状态 | 闭源，仅 API |

## Gemma 4 12B Unified — 统一多模态架构

**日期**：2026-06-03
**提供方**：Google DeepMind
**来源**：[Gemma Releases](https://ai.google.dev/gemma/docs/releases)
**可信度**：🟢 官方

### 是什么
- 模型类型：多模态（统一架构，无需额外视觉编码器）
- 核心亮点：
  - 12B 参数，可在消费级 GPU / Apple Silicon 上运行
  - 统一文本+视觉处理，部署更简单
  - Gemma 4 家族：E2B、E4B、26B A4B、31B Dense、12B Unified

### 有什么用
- **移动端多模态**：12B 尺寸适合本地部署多模态应用
- **离线场景**：与 Qwen3-Omni 互补，提供 Google 生态的多模态开源选项
- **快速原型**：无需复杂的视觉编码器管线，开箱即用

### 关键数据
| 指标 | 值 |
|------|-----|
| 参数规模 | 12B（Unified） |
| 上下文窗口 | 256K |
| 部署环境 | 消费级 GPU / Apple Silicon |

**提供方**：DeepSeek
**来源**：[DeepSeek API 公告](https://deepseekv4.network/)
**可信度**：🟢 官方
