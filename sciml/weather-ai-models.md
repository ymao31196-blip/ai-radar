# 气象/气候 AI 模型

> 覆盖：FourCastNet、GraphCast、Pangu-Weather、Aurora
> 这些模型用于全球/区域气象预测，是风场降尺度任务的上游输入来源。
>
> 💡 **降尺度（downscaling）**：将全球粗分辨率气象预报（通常网格间距几十公里）细化到风场级的精细分辨率（几公里甚至几百米），是风电功率预测的关键前置步骤。

---

## 背景：ECMWF 的外部 AI 模型运行情况

截至 2026 年初，ECMWF（欧洲中期天气预报中心）每日运行以下 AI 气象模型，初始场来自 IFS（综合预报系统，ECMWF 的核心数值天气预报模型）业务分析，每日 0 和 12 UTC（协调世界时，对应北京时间早 8 点和晚 8 点）各跑两次：

- **FourCastNet** (Nvidia)
- **GraphCast** (Google DeepMind)
- **Pangu-Weather** (Huawei)
- **Aurora** (Microsoft Research)

ECMWF 的 AIFS（AI 集成预报系统）逐步成熟后，计划逐步减少对外部模型的依赖。但这些模型的开源权重和推理代码仍然可用，是风场降尺度研究的黄金基线。

## FourCastNet — Nvidia

**类型**：全球气象预报模型
**日期**：2023-03
**来源**：https://arxiv.org/abs/2202.11214
**可信度**：🟢 已发表

### 是什么
基于 AFNO（Adaptive Fourier Neural Operator，自适应傅里叶神经算子——在频率域做计算，类似把空间画面"翻译成"频率成分再处理）的全球天气预报模型。在 ERA5（全球气象再分析数据集，由 ECMWF 提供，覆盖 1940 年至今）再分析数据上训练，0.25° 分辨率（约 30km），预测 6 小时间隔的全球大气状态。

### 通俗解释
FourCastNet 像一个轻量的全球天气快速预测器：它不按传统物理模式一步步解方程，而是学会从历史气象网格中快速推出未来状态。对风电降尺度来说，它可以先提供粗分辨率风速和天气背景，再交给下游模型细化到风场尺度。

### 对风电/降尺度有什么用
- **最轻量的公开气象模型**：单 GPU 可跑，硬件门槛最低
- **FNO 架构的可迁移性**：AFNO 的傅里叶层设计本身就适合降尺度——从粗网格（全球）到细网格（区域）的映射是算子学习的天然场景
- **频域特征提取**：风电场的湍流、尾流等小尺度现象在频域有特殊分布，FNO 类模型的频域操作可能比其他架构更高效

### 关键信息

| 维度 | 内容 |
|------|------|
| 模型架构 | AFNO（Adaptive Fourier Neural Operator） |
| 输入模态 | 全球网格（0.25°, 720×1440） |
| 输出类型 | 全球气象场预测（10m 风速、2m 温度、位势高度等） |
| 预训练数据 | ERA5 再分析数据（1979-2015） |
| 开源状态 | ✅ 开源（Nvidia 官方） |
| 论文 | https://arxiv.org/abs/2202.11214 |
| 代码 | https://github.com/NVIDIA/FourCastNet |

### 适用场景
- 全球 NWP（数值天气预报）输出的快速替代（比传统数值模式快 1000x）
- 降尺度研究的输入层（从全球 0.25° 降尺度到 1-3km 风场级）
- 集成预测（Ensemble）的快速成员生成

### 局限性 / 已知问题
- 仅预测地表变量，无垂直层信息
- 预测时效约 7 天，更长 horizon 精度下降明显
- FN 版本更新后计算量有所增加

## GraphCast — Google DeepMind

**类型**：全球气象预报模型
**日期**：2023-11（Science）
**来源**：https://www.science.org/doi/10.1126/science.adi2336
**可信度**：🟢 已发表（Science）

### 是什么
基于图神经网络（GNN，把地球表面看作一张由节点和边组成的网，在相邻节点之间传递气象信息）的全球天气预报模型。核心设计是在六面体网格（icosahedral mesh，将球面均匀划分为三角形，6 个三角形合成一个六边形，解决了经纬网格在极点处严重变形的问题）上运行 GNN 消息传递，支持多变量（包括 37 个垂直层）和多重网格分辨率。在中长期预报中，90% 的目标指标超过 ECMWF HRES（高分辨率预报系统，ECMWF 传统数值模式的最高分辨率版本）传统数值模式。

### 通俗解释
GraphCast 把地球天气看成一张巨大的关系网：一个地方的气压、温度、风速会影响邻近地方，模型就在这张网上传递信息。它包含垂直层数据，所以不只是知道地面风，还能帮助推算风轮高度附近的风，对风电功率预测更关键。

### 对风电/降尺度有什么用
- **垂直层信息**：包含 37 层大气垂直层数据，对边界层风速垂直廓线建模极为重要——直接关联风轮高度（~100m）的风速推算
- **图网格天然适配不规则分布**：风场内测风塔、激光雷达的位置是不规则离散点，GNN 的消息传递可以直接映射到这种非网格结构上
- **Science 级别验证**：全局预报精度经严格验证，作为降尺度输入的可靠性最高

### 关键信息

| 维度 | 内容 |
|------|------|
| 模型架构 | GNN（六面体网格消息传递） |
| 输入模态 | 网格 + 垂直层 + 多变量 |
| 输出类型 | 全球气象场（10天预报，0.25°） |
| 预训练数据 | ERA5 再分析数据（1979-2017） |
| 开源状态 | ✅ 开源（DeepMind） |
| 论文 | https://www.science.org/doi/10.1126/science.adi2336 |
| 代码 | https://github.com/google-deepmind/graphcast |

### 适用场景
- 风轮高度（~100m）风速的 NWP 输入生成
- 基于 GNN 的降尺度模型架构参考
- 中长期（3-10天）风功率预测的上游气象输入

### 局限性 / 已知问题
- 推理耗时较长（显存消耗大）
- 图网格构建的预处理代码复杂
- 开源代码使用的 JAX 生态，与 PyTorch 项目集成需额外工作

## Pangu-Weather — Huawei

**类型**：全球气象预报模型
**日期**：2023-07（Nature）
**来源**：https://www.nature.com/articles/s41586-023-06185-3
**可信度**：🟢 已发表（Nature）

### 是什么
华为推出的 3D Earth-Specific Transformer。使用立方体球面表示（cubed sphere，把地球表面"包"在一个立方体里，再投影到 6 个正方形平面上——一种避免极区畸变的地球网格方案）将地球表面投影到 6 个平面上，再堆叠 Transformer 层处理。在 1 小时、3 小时、6 小时、24 小时预测步长上都超过传统数值模式 IFS。

### 通俗解释
Pangu-Weather 的直观思路是给地球换一种更适合模型处理的地图。经纬度网格在两极会变形，立方体球面把地球摊到 6 个面上，模型更容易稳定学习全球天气变化。它对风电的启发是：不同预测时长可以用不同模型专门优化。

### 对风电/降尺度有什么用
- **Nature 级别验证**：预测精度经过 Nature 同行评审，可靠性有保障
- **多步长训练策略**：不同预测步长使用不同模型，这种策略可直接迁移到风电的多时间尺度预测（15min / 1h / 6h / 24h）
- **3D 地球表示**：立方体球面对边界层和大尺度环流的表示可能优于经纬网格（极区畸变问题）

### 关键信息

| 维度 | 内容 |
|------|------|
| 模型架构 | 3D Earth-Specific Transformer + Cubed Sphere |
| 输入模态 | 全球网格 + 多变量 + 垂直层 |
| 输出类型 | 全球气象场（7天预报） |
| 预训练数据 | ERA5 再分析数据（1979-2018） |
| 开源状态 | ⚠️ 权重开源，部分代码 |
| 论文 | https://www.nature.com/articles/s41586-023-06185-3 |
| 代码 | https://github.com/198808xc/Pangu-Weather |

### 适用场景
- 需要高可靠性气象输入的降尺度研究
- 多时间尺度预测策略参考（不同 horizon 用不同模型）
- 立方体球面表示在区域降尺度中的应用研究

### 局限性 / 已知问题
- 四个预测模型（1h/3h/6h/24h）分别推理，总资源消耗较大
- 权重已开源但官方代码不完整，社区维护版本质量参差不齐

## Aurora — Microsoft Research

**类型**：地球系统基础模型
**日期**：2024-06（Nature 正刊发表）
**来源**：https://www.nature.com/articles/s41586-025-09005-y
**可信度**：🟢 已发表（Nature）

### 是什么
Microsoft Research 开发的地球系统基础模型，基于 Swin Transformer + 3D感知器架构。不同于其他模型仅限天气预报，Aurora 覆盖空气污染、海洋状态、极端天气等多种地球系统变量。支持灵活的分辨率和变量组合输入/输出。

### 通俗解释
Aurora 更像“地球系统通用模型”，不只预测天气，还能处理海洋、污染和极端天气相关变量。对海上风电来说，风不是单独存在的，还会和浪、流、气溶胶等因素耦合；Aurora 的价值就是把这些更广的地球系统信息纳入同一框架。

### 对风电/降尺度有什么用
- **多种地球系统变量**：除风速外，还能输出湍流、气溶胶、海洋状态等——对海上风电的浪-风耦合建模很有价值
- **灵活分辨率**：原生支持 0.1°~1° 范围内的不同分辨率输入输出，不需要额外插值——这本身就是降尺度能力
- **小样本微调**：在大规模地球系统数据上预训练后，在特定任务（如区域降尺度）上仅需少量数据即可微调

### 关键信息

| 维度 | 内容 |
|------|------|
| 模型架构 | Swin Transformer v2 + 3D Perceiver |
| 输入模态 | 网格 + 多变量 + 垂向/水平可调分辨率 |
| 输出类型 | 大气/海洋/空气污染多变量预报 |
| 预训练数据 | 百万小时级地球系统数据 |
| 开源状态 | ⚠️ 权重可用，完整训练代码未公开 |
| 论文 | https://www.nature.com/articles/s41586-025-09005-y |
| 代码 | https://github.com/microsoft/Aurora |

### 适用场景
- 海上风电的浪-风-流耦合预测
- 区域降尺度（原生可变分辨率）
- 极端天气（台风、寒潮）下的风功率预测

### 局限性 / 已知问题
- 完整训练代码未公开，只能做推理和微调
- 推理资源需求高（多 GPU）
- 2026年初 ECMWF 已停止日常运行 Aurora（AIFS 替代），但权重仍可用

## NOAA 新一代 AI 全球天气预测模型

**日期**：2026-06（部署上线）
**来源**：[NOAA 官方新闻](https://www.noaa.gov/news-release/noaa-deploys-new-generation-of-ai-driven-global-weather-models)
**可信度**：🟢 官方

### 核心思路
NOAA（美国国家海洋和大气管理局）部署新一代 AI 驱动的全球天气预测模型，在预报速度、效率和准确性上取得显著提升，同时仅使用传统数值模型一小部分的计算资源。

### 通俗解释
NOAA 这条的意义在于 AI 天气模型从论文和实验室走进国家级业务系统。以前 AI 气象更多是“研究模型能不能打过传统数值预报”，现在政府气象机构开始部署，说明它可能成为未来风电预测上游数据源的一部分。

### 关键亮点
- **速度提升**：AI 模型推理速度远快于传统 NWP（数值天气预报）
- **效率**：计算资源消耗大幅降低
- **准确性**：在多项指标上持平或超越传统模型
- **业务化部署**：这是 AI 天气模型从研究走向国家级业务化的重要里程碑

### 与现有模型的关系
| 维度 | NOAA AI 模型 | FourCastNet | GraphCast | Pangu-Weather |
|------|-------------|-------------|-----------|---------------|
| 状态 | 🟢 业务化运行 | 🔵 开源研究 | 🔵 开源研究 | 🔵 开源研究 |
| 机构 | NOAA（政府） | NVIDIA | DeepMind | 华为 |
| 风电价值 | 待评估 | ⭐⭐⭐ 轻量 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ |

### 有什么用
- **国家级业务化信号**：AI 天气模型正在从学术研究走向政府业务系统 — 这是行业成熟的标志
- **风电降尺度机遇**：NOAA 的开放数据传统意味着其 AI 模型输出可能公开可用，可考虑作为区域降尺度的上游数据源
- **行业对标**：如果 NOAA 级别的机构已采用 AI 模型替代/补充 NWP，其他气象机构将加速跟进
